 Das Leben ist aber komplex — Lebewesen sind ständig wechseln-
 den Einflüssen aus verschiedenen Richtungen ausgesetzt. Um das
 Gleichgewicht (Homöostase) zu erhalten, braucht es deshalb selbst-
 verständlich Regulationsmöglichkeiten in beide Richtungen. Ideal
 ist dabei ein mittleres Aktivitätsniveau. Ein solches kann erreicht
 werden, weil in unseren Körperzellen nicht nur eine einzige Kopie
 des jeweiligen Lithiumtargets aktiv ist. Wäre dies der Fall, hätte ein
 Lithiumion, welches ein Magnesiumion verdrängt, ein Abschalten
 des Gesamtsystems zur Folge. Es verhält sich aber so, dass in den
 Zellen Tausende von Kopien eines jeweiligen Lithiumtargets exis-
 tieren. Das Gesamtsystem kennt kein absolutes aktiv oder inaktiv,
 sondern einen variablen Mischzustand aus einem aktiven Teil (Ma-
 gnesiumionen gebunden) und einem inaktiven Teil (Lithiumionen
 gebunden). In diesem Sinne möchte ich, um die Automobil-Meta-
 pher noch etwas weiter zu bemühen, von einer Regulation auf ein
 geringfügig aktives Niveau durch Lithium sprechen. Zum Vergleich:
 Ein typischer Automotor wird auf eine Leerlaufdrehzahl von etwa
 800 Umdrehungen pro Minute eingestellt, damit er auch im Ruhe-
 zustand jederzeit fahrbereit bleibt, während der Kraftstoffverbrauch
 und der Verschleiß minimiert werden.
Bei Lithiumtargets wäre das System hyperaktiv, wenn im intra-
 zellulären Milieu nur Magnesiumionen und praktisch keine Lit-
 hiumionen vorhanden wären. In diesem Fall würde das System auf
 voller Leistung arbeiten. Aber so, wie ein Motor überhitzt und auf
 Dauer Schaden nimmt, wenn er ständig überdreht, so nimmt auch
 der Organismus auf Dauer Schaden, wenn eine gesunde Homöos-
 tase aufgrund eines Lithiummangels nicht erreicht werden kann.
