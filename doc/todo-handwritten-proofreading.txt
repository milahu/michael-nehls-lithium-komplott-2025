for each HOCR file:

print a human-readable and machine-readable version of the HOCR file.
prefix each line with its line number.
add a running header and footer with the book title and the HOCR filename.

specify some way for handwriting proofreaders to propose edits to the HOCR file.
example:
"X in the space between two paragraphs" means "join these paragraphs".
"- between two lines" means "split these lines"

each line is followed by an empty line
where the proofreader can insert the correct text

each printed page contains
the scanned image on the left half
the HOCR text on the right half

the HOCR text font size is stretched
so the scanned font size and the HOCR text font size are similar

when the handwriting proofreader is done with a page
he scans the page with his handwritten corrections
and the script parses and applies these corrections to the HOCR files

so this also requires OCR of handwriting
which is a solved problem with
https://github.com/ahnafnafee/local-llm-pdf-ocr

$ local-llm-pdf-ocr --help
usage: local-llm-pdf-ocr [-h] [--verbose] [--quiet] [--dpi DPI] [--pages PAGES] [--concurrency CONCURRENCY] [--no-refine] [--max-image-dim MAX_IMAGE_DIM]
                         [--dense-threshold DENSE_THRESHOLD] [--dense-mode {auto,always,never}] [--grounded] [--api-base API_BASE] [--model MODEL]

OCR with Local LLM - turn scanned PDFs or raw images into searchable PDFs.

positional arguments:
  input                 Path to a PDF or image file (JPEG/PNG/TIFF/BMP/WebP/AVIF). Multi-frame TIFFs expand to multiple output pages.
  output                Path to output PDF (always a PDF, even for image inputs; defaults to <input_stem>_ocr.pdf).

options:
  -h, --help            show this help message and exit
  --verbose, -v         Enable verbose debug logging
  --quiet, -q           Suppress all output except errors
  --dpi DPI             DPI for image rendering (default: 200)
  --pages PAGES         Page range to process, e.g., '1-3,5' (default: all)
  --concurrency CONCURRENCY
                        Parallel LLM requests (default: 1)
  --no-refine           Skip per-box crop re-OCR for low-confidence boxes (faster, less accurate on complex layouts)
  --max-image-dim MAX_IMAGE_DIM
                        Longest-edge px cap for page images sent to the LLM (default: 1024). Drop to ~640 for small local VLMs like GLM-OCR:1.1B that
                        crash on larger inputs.
  --dense-threshold DENSE_THRESHOLD
                        In --dense-mode auto, pages with more than this many detected boxes use per-box OCR instead of full-page (default: 60). Per-box is
                        more accurate on dense handwritten content where the LLM otherwise loops or hallucinates.
  --dense-mode {auto,always,never}
                        auto (default): per-box OCR for pages above --dense-threshold. always: per-box for every page (slow but most accurate). never:
                        original full-page OCR everywhere.
  --grounded            Use a bbox-native VLM (Qwen2.5-VL / Qwen3-VL / etc.) that returns text WITH bounding boxes in one call. Skips Surya + DP + refine.
                        Requires --model to be a vision LLM that supports grounded output.
  --api-base API_BASE   Override LLM API base URL
  --model MODEL         Override LLM model name

Examples:
  local-llm-pdf-ocr input.pdf output_ocr.pdf
  local-llm-pdf-ocr scan.png                       # Image input - auto-generates scan_ocr.pdf
  local-llm-pdf-ocr pages.tiff                     # Multi-frame TIFF - one output page per frame
  local-llm-pdf-ocr input.pdf                      # Auto-generates input_ocr.pdf
  local-llm-pdf-ocr input.pdf output.pdf --verbose
  local-llm-pdf-ocr input.pdf output.pdf --pages 1-3,5
  local-llm-pdf-ocr input.pdf output.pdf --dpi 300 --api-base http://localhost:1234/v1
